一、 审核维度与细分检查项
--------------------------------------------------------------------------------

请按以下 9 大核心维度对代码库进行逐项剖析，明确标出“优秀设计（Highlights）”、“潜在缺陷（Defects / Risks）”及“工业级改进建议（Recommendations）”：

### 1. 战略方向与工业业务对标（Product Direction & OLP Benchmarking）
- 对标 FASTSUITE Edition 2 / Robotmaster / Delmia 的离线编程标准闭环：工位装配导入 -> 焊缝特征识别 -> 工艺轨迹生成 -> 逆解与姿态优化 -> 扫掠干涉检查 -> 仿真烘焙 -> 机器人代码生成（.ls / .src 等）。
- 离线编程（OLP）与一般三维仿真（Simulation）的本质区别：软件是否具备工业级示教契约？工艺事件（起弧 Arc Start、收弧 Arc End、摆焊 Weave）与运动轨迹是否强关联？
- 当前对标单工位单机器人弧焊，其架构是否具备扩展至变位机协同（Coordinated Motion with External Positioner）、双机协作、激光切/打磨等多种工艺的能力？

### 2. 系统分层架构与解耦度（Architecture & 5-Layer Decoupling）
- 项目制定的五层解耦设计规范（Core -> Algo -> Device -> IO -> UI）落实情况：
  1. `olp_core`: 纯核心数据结构与数学类型，是否严格零第三方库依赖（无 Qt、无 OCCT、无 FCL）？
  2. `olp_cad`: CAD 几何内核抽象与 B-Rep 解析，是否做到了与具体内核的抽象隔离（ICadKernel 接口与 OcctCadKernel 实现）？
  3. `olp_device`: 机器人运动学模型与机构参数抽象是否独立于算法？
  4. `olp_algo`: 运动学（OPW）、刀轨生成、自转角优化、FCL 碰撞引擎，是否做到了无 UI 依赖、可在无头（Headless）CI 环境独立运行？
  5. `olp_io`: 工程序列化（JSON）、FANUC .ls 后处理器、HTML 3D 导出是否与业务状态完全解耦？
  6. `olp_ui`: Qt6 与 OpenCASCADE 视口、Dock 体系、Gizmo 手柄等是否只作为视图与控制器？是否存在算法侵入 UI 或 UI 反向污染算法的情况？
- 依赖倒置、PIMPL 模式、模块间编译防火墙（Header Hygiene）与头文件循环依赖检查。
- 单文件行数硬性约束（< 1000 行，硬上限 1500 行）执行情况与代码物理划分质量。

### 3. 机器人运动学与几何算法深度（Kinematics & Geometric Algorithms）
- **OPW 解析运动学算法（OpwKinematics）**：
  - 对 FANUC M-10iA / ARC Mate 100iC 典型六轴关节机器人的几何参数（$c_1, c_2, c_3, c_4, b, a_1, a_2$）解析闭合解的准确性与数值稳定性；
  - J2/J3 平行连杆解耦处理（Coupling: $\theta_3 = \theta_3^{urdf} - \theta_2^{urdf}$）与轴限位映射；
  - 8 组逆解分支提取、构型标记（Flip / Up / Front）与多圈计数（Turns）的一致性；
  - 腕部奇异（Wrist Singularity, J5 near 0）、肘部奇异（Elbow Singularity）、肩部奇异（Shoulder Singularity）的判定裕量与避奇异策略；
  - 笛卡尔运动段（Linear Move）配置跳跃（Config Jump）的动态甄别。
- **焊缝与刀轨生成算法（SeamAndToolpathAlgo）**：
  - 基于 CAD B-Rep 几何的双侧面角平分线（Dihedral Angle Bisector）标架构建稳定性；
  - 焊枪姿态倾角（Push/Drag Angle）、工作倾角（Work/Tilt Angle）与离散采样法向量正交化；
  - 焊缝起弧延伸/内缩（Start/End Trim）与引退弧路径平滑生成；
  - 焊枪本地 TCP Z 轴自转（Twist Angle）优化策略与 72 组采样扫查机制。

### 4. 碰撞检测与干涉安全计算（Collision & Clearance Engine）
- **FCL (Flexible Collision Library) 深度集成**：
  - 机器人连杆 BVH 网格模型（OBBRSS 层次包围盒）与场景几何的距离计算（`queryDistanceMm`）；
  - 宽相 AABB 距离裁剪算法的严密性与剪枝效率，是否有效避免无碰撞部件的冗余 BVH 树遍历；
  - 焊丝尖端豁免机制（Wire-Tip Collision Exemption）：在焊缝根部焊接状态下，是否既能有效防止焊丝与母材误报碰撞，又能严格阻断焊枪喷嘴/导电嘴与夹具母材的硬接触。
- **连续扫掠碰撞检测（Continuous Sweep Collision）**：
  - 直线段（SLERP 插值）与关节插值（Joint Move）的中间态离散步长与覆盖度；
  - 碰撞预警间隙（NearCollision Clearance）与绝对碰撞（Hard Collision）的分类判定与性能平衡。

### 5. 工业后处理与代码级契约（Post-Processor & Controller Rigor）
- FANUC ASCII `.ls` 代码生成合规度：
  - `/PROG`, `/ATTR`, `/APPL`, `/MN`, `/POS`, `/END` 的段落格式；
  - 运动指令语法（`J P[1] 50% FINE`, `L P[2] 1000mm/sec CNT100`）；
  - 焊机专用工艺指令（`Arc Start[1]`, `Arc End[1]`）的时序与位置匹配；
  - 构型标志串（`N U T, 0, 0, 0`）与关节圈数编码在奇异点附近的可靠性；
  - 错误防御：当目标点存在不可达、超限位、配置跳变或碰撞时，后处理器是否具备绝对拒止机制，防止错误程序下发真机撞机。

### 6. UI 交互体验、3D 视口与状态同步（UI Ergonomics, Viewport & State Sync）
- **OpenCASCADE 3D 视口渲染与交互**：
  - 工业转盘相机（Turntable Orbit）：世界 Z 轴锁定、Roll 恒为 0、水平 360 度与垂直 [-88°, +88°] 极角约束的数学实现健壮性；
  - 鼠标拾取（Edge/Face Picking）精确度与高亮显示性能；
  - `TcpGizmo` 示教手柄：世界坐标系（World）、工具坐标系（Tool）、工件坐标系（UFrame）、焊缝坐标系（Seam）多标架自由切换与平移/旋转解耦数学转换；
  - 吸附步进（Linear Snap / Angular Snap）的直观性。
- **Qt6 布局与多窗口弹性**：
  - 复杂嵌套 DockWidget 的尺寸约束防护，`QScrollArea` 避免分割条死锁机制；
  - 深色高对比度主题样式规范与自绘控件渲染质量。
- **CommandManager 撤销/重做架构**：
  - 100 步 Undo/Redo 事务对称性与文档状态同步；
  - 拖拽过程中的实时轻量预览（Preview）与松手提交（Commit）隔离，避免 Undo 栈污染；
  - 重型计算（如自转扫描、全轨迹仿真、FCL）与 UI 主线程的异步解耦（QThreadPool / std::atomic 取消令牌）。

### 7. 现代 C++20 语言标准、内存安全与健壮性（Modern C++ & Safety）
- C++20 现代特性使用规范度（Concepts, `std::span`, `std::optional`, `<format>`, `constexpr` 等）。
- 内存所有权与生命周期管理：指针使用是否严谨（无悬挂引用、无非法强转、无内存泄漏）。
- 线程安全性：静态资产缓存（RobotMeshAsset、SceneBvhItem）的互斥锁保护，后台线程访问文档模型的数据隔离。
- 数值计算健壮性：三角函数反函数（`asin`/`acos`）越界防护、零向量正交化/归一化防护、浮点比较容差（`1e-9`）。
- 字符编码与跨平台兼容性：UTF-8 中文工程路径与 Windows wide-string 互转支持。

### 8. 自动化测试体系与回归防护（Verification & Test Harness）
- 现有 759 个自动化测试覆盖范围与测试金样质量：
  - 运动学正逆解闭环（100 组随机姿态闭环差 < 1e-4 mm）；
  - URDF 链真值几何比对；
  - 跨零件 T 型接头端到端回归（工位导入 -> 识别 -> 轨迹 -> 碰撞 -> 仿真 -> 导出）；
  - 撤销重做 100 步状态恢复一致性。
- 测试用例设计的边界条件、退化情况（Degenerate Cases）以及负向测试（Negative Testing）是否充分。

### 9. 性能瓶颈分析与高并发潜力（Performance & Scalability）
- 内存足迹与大装配（几百兆 STEP、数万三角形）的承载极限。
- 视口 FPS、文档刷新延迟、路径编辑响应延迟分析。
- 多核并行加速潜力（如并行逆解求解、多目标点并行碰撞查询）。
