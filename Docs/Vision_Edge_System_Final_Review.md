## 1. 终审发现

### F1【物理·高】板在边端会被“拧转”，0.8 N 判据在小托台上失效

**问题**：v1.0 和 Opus 原文都按“平移推板”算临界力 $F_{push}=\mu G$。但滚轮接触力的作用线只有在边中点才穿过板的摩擦中心；接触点走到边端头、绕凸角时，作用线偏离中心 ~L/2，板会绕支撑区内某个瞬心**转动滑移**，临界力远小于 $\mu G$。

**计算**（均匀压力库仑摩擦，瞬心法数值求解；脚本 `Docs/assets/vision_edge/calc_push_rotation.py`）：

| 工况 | 临界力 / $\mu G$ | 200 板（G=4.2 N，μ=0.7）临界力 | 对 0.8 N 的安全系数 |
| :-- | :-- | :-- | :-- |
| 任意托台，推边中点 | 1.00 | 2.94 N | 3.7 |
| 170 方满托，推边端头 | 0.525 | 1.54 N | 1.9 |
| Ø70 圆托，推边端头 | 0.224 | 0.66 N | **0.8（会转）** |
| Ø50 圆托，推边端头 | 0.163 | 0.48 N | **0.6（会转）** |
| 300 板（G≈9.5 N）/ Ø70 圆托，推边端头 | 0.153 | 1.02 N | 1.3 |

**为什么只能用小托台**：P0 板型 100~300 mm，托台外缘必须缩进板边 ≥ R+5 = 15 mm（防辊碰托台），所以同一个托台必须放得进最小的 100 mm 板 → 托台直径 ≤ 70 mm。也就是说，**不加吸附时，在 P0 板型范围内防推判据必然失效**。

**决议**：
- **中心真空吸附从“可选”升级为 P0 标配**：Ø40~50 小托台 + 中心吸盘（Ø40 吸盘在 −50 kPa 下法向保持力 ≈ 63 N），转动临界力约 $(0.13\sim0.16)\times0.6\times(4.2+63)\approx 5\sim6\text{ N}$，安全系数约 6~8。推荐用电动微型真空泵，现场不需要气源。
- S0-4 改为**在边中点、边端头、拐角三个位置**实测临界力，判据取三者中的**最小值**的 1/3。
- M07 增加“吸附建立（真空压力开关 DI 到位）才允许执行”的互锁。
- 新增风险：MDF/胶合板底面透气或不平会让真空度下降【待核，S0-4 实测】。
- 附带好处：拐角减压退让正好落在最容易拧转的位置，与防拧转方向一致。

### F2【算术·高】人天上限是 147，不是 145

各阶段上限：32 + 34 + 28 + 24 + 22 + 7 = **147**（金额上限 32.34 万元），与总计 145 / 31.9 万元不一致。下限 125 / 27.5 万元正确。

**决议**：不简单抬价，而是删一项过度设计：**S0-7（Eye-to-Hand 与 Eye-in-Hand 对比）改为条件触发**。理由是 Opus 原文 §4.2 已论证 Eye-in-Hand 在 P0 的每个维度（视差带更宽、镜头溅漆、占负载、拍照位误差进入结果）都不占优，唯一优势“分辨率”已有更便宜的退路（S0-2 的 2D 辅助相机）。只有在 S0-2 用 Eye-to-Hand 未达标、且 2D 辅助相机也不能解决时才做 S0-7。阶段 0 由 28~32 改为 **28~30 人天**，合计恢复为 **125~145 人天 / 27.5~31.9 万元**，与已对外口径一致。

### F3【范围·中】“随手放”与小托台需要明确的摆放公差

吸盘必须被板完全覆盖、托台必须缩进板边 ≥ R+5，于是板中心相对托台中心的允许偏移为

$$e_{\max}=\frac{W_{\min}}{2}-(R+5)-r_{ped}$$

（$W_{\min}$ 为板的最小宽度，$r_{ped}$ 为托台半径）。取 Ø50 托台、R=10：100 板 ±10 mm，200 板 ±60 mm，300 板 ±110 mm；角度 0~360° 任意。
**决议**：P0 摆放定义改为“任意角度 + 板中心落在上述偏移圈内”，托台表面刻对中标线；M03 检测到托台外露或偏移超限时拒绝执行并提示重放。

### F4【工艺·中】接触力有“窗口”，S0-4 和 S0-5 必须联做

- 接触力上限由防推决定，**下限由上漆决定**：压力太小海绵不出漆。v1.0 只写了上限。
- 浮动机构和海绵是**串联弹簧**：浮动越软，同样的总压紧量下海绵本身被压缩得越少，出漆越少。0.2 N/mm 是串联等效刚度，海绵实际压缩量要在 S0-4 的力—位移曲线里分开测。
- 竖直安装的辊，涂料会在重力作用下往下端沉积：侧面下部偏厚、待机时从下端滴漆。
**决议**：S0-5 必须在 S0-4 确定的压紧量下进行；S0-5 增测“板厚方向上下膜厚均匀性”和“待机 60 s 滴漆量”。

### F5【参数·中】拐角参数被固化成“红线”，属于过度约束

- 误差预算 2σ ≈ ±1.3 mm。拐角压紧量减到 $\delta_c=1.25$ mm 时，在 −1.3 mm 的系统偏差下会**脱离接触**，角上干涂。
- 系统偏差主要来自标定和机器人绝对精度，在工作区内缓慢变化，不能靠一个固定百分比同时兼顾“不积漆”和“不脱离”。
**决议**：$k_c$（恢复为 2~3，初值 2.5，受加速度限制）和 $\delta_c$（初值 $0.5\delta_0$）都改为**配方参数**，在 S0-6 和阶段 4 调优；验收只看结果（拐角无积漆、无干涂），不再把数值写成工艺红线。

### F6【验收·中】验收指标缺少生效条件，并丢了端到端指标

1. 丢失 Opus 原文中**最能反映全链路误差的指标**：刚性假辊空跑（名义间隙 2 mm），8 个采样点实测间隙 2 ± 0.8 mm。已补回。
2. 丢失“台面/托台无沾漆”。已补回。
3. 视觉精度 RMS ≤ 0.3 mm 只有工业近距结构光有希望达到；如果用户选 RealSense D405，不能预先承诺这个数。
4. v1.0 写“作为商务结算的法律凭据”过早，Q1~Q7 尚未确认。
**决议**：验收标准改为“合同技术附件”，生效条件为：① 阶段 0 三条红线通过，或已书面约定退路；② 使用工业级结构光相机（选 D405 时视觉/标定指标在 S0-2 后按实测重定）；③ 现场条件与 Q1~Q7 确认书一致。

### F7【工期·中】硬件采购周期会吃掉阶段 0

阶段 0 只有 3 周，而工业相机采购约 2~4 周【待核】，CNC 测试板（带计量报告）和末端浮动头也要外协加工。如果工期从签约日起算，阶段 0 几乎肯定延期。
**决议**：商务前提写明“**工期自相机、机器人、真空吸附组件、CNC 测试板到位之日（T0）起算**”；签约后第 1 天下单。

### F8【文档·低】其余修正

- 正文所有经验值、厂商宣传值的【待核】标注被全部删掉，违反 Rules 的信源要求 → 已恢复（μ 值、误差预算、相机标称值、吸盘保持力等）。
- 误差预算 RSS 复算为 0.67 mm（1σ）/ ±1.34 mm（2σ），v1.0 写的是 0.65 / ±1.30 → 已更正。
- M04 判据“ρ < R 标红”不准确 → 改为两级：ρ < 2R 超出 P0 范围（警告），ρ ≤ d 物理不可达（标红并列入报告）。
- Z 向覆盖规则丢失 → 补回：辊有效段覆盖 $[Z_{top}-H-m_b,\ Z_{top}-m_t]$，辊下端距工作台面 ≥ 5 mm。
- 风险清单、运行状态机、HW 交付物（含标定附件和 6 种 CNC 测试板）、团队配置、P1 估算（+5~6 周 / +50~65 人天）丢失 → 已补回。
- S0-6 退路“改用伺服点流”丢失 → 已补回。
