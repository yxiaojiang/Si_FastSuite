## B. 技术错误（必须改）

### B1 【物理错误】防推板的力学判据被降级
- 收敛稿：“平放木板摩擦极限约 1.3 N，接触力 ≤ 0.8 N 可防推”。
- 问题：1.3 N 是**光滑台面**（μ≈0.3）上的值。Opus 的判据是**法向力 ≤ 静摩擦的 1/3**，0.8 N 只在**防滑硅胶垫**（μ≈0.6~0.8，静摩擦 2.5~3.4 N）上成立。在光滑台面上，安全系数只有 1.6，而不是 3。光滑台面上的正确上限约为 **0.43 N**。
- 漏掉的部分：被动辊的**滚动阻力和轴承摩擦**也会产生切向力（会给板一个力矩），收敛稿完全没提，需要在阶段 0 的推板测试里一起测。
- Opus 自查：原文 §2.3 暗坑 2 先列 1.3 N、再给 0.8 N，没有写明前提，这个歧义是 Opus 自己留下的，Gemini 照搬后放大了。μ 值本身也是【待核】。

### B2 C1 夸大效果
- “彻底消除拐角积漆”：错。$k_c=2.5$ 时接触点仍然会在角上停留 **0.27 s**，只是从 0.67 s 降下来，原理上无法消除（尖角处接触点速度一定为 0）。
- $k_c$ 被收窄成 2~2.5（原文是 2~3，并受加速度限制）。

### B3 阶段 0 Spike 被重新编号，内容也被删改

## C. 关键内容丢失（影响报价和验收）

1. **待确认问题被替换**：Opus 的 **Q4“动态”的含义**（每次现拍现算，还是执行过程中实时跟踪）被换成了“节拍”。这对应风险 R10（影响高），用户原话就是“动态操作”，**必须问**。Q3 里“小圆柱是被动随动还是电机驱动”也被删掉了。附加问题“演示样机还是生产使用”也丢了。
2. **§11 量化验收标准完全没有进入收敛稿**：报价单和合同需要这些指标。
3. **误差预算和压紧量**：名义压紧量 δ₀≈2.5 mm（范围 1~4 mm）、等效刚度 ≤ 0.2 N/mm 都丢了。Gemini 原来的 1.0~1.5 mm 会导致悬空漏涂，这一条修正没有被记录下来。
4. **报价附加条件**：FANUC 等工业臂 +10~15 人天，去掉托台 +5 人天，改用蠕动泵 +5~8 人天，硬件费用另计。这些都没有写进 Plan，报价单会漏掉前提条件。
5. **相机**：Q2 写成了“千元级 RealSense / 奥比中光”。Opus 已经明确不推荐奥比中光的 Femto Bolt（ToF）和 Gemini 335L，低成本对照应写 **RealSense D405**。
6. 其他细节：复拍阈值（0.5 mm / 0.3°）、凹角不可达段标红、底端距托台面 ≥ 2 mm、$m_t/m_b$ 包边策略都没进入上下文。
7. 文字小错：“垫高**温台**”应为“垫高托台”；“摆放位置任意”应为“在托台和可达性热图范围内”；托台写成“强制”，但 Q4 还在等用户确认，前后矛盾。
