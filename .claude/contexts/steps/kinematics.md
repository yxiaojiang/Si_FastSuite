# 运动学

1. **关节链改成四段，正逆对称。** 示教器关节角先在 URDF 空间做 J2/J3 耦合，再 `q = 符号 × J − 存储偏置`，然后进入 OPW。存储偏置不是 ROS-Industrial 那种直接相加；J3 存储偏置 −90°、符号 −1，才对应 ROS 偏置 +90°。耦合不能写进 OPW 角，否则前臂绝对角会变成两倍 J2 加 J3。
2. **用独立 URDF 链做金标准。** 零位法兰约在 (890, 0, 1200) mm，工具 Z 轴朝 +X，与 `tool0` 对齐。两百组样本位置误差小于 0.01 mm。连杆网格坐标系仍是 OPW 抽象，没有逐节对齐 URDF 网格。
3. **J6 折回示教器时归一化到 (−π, π]。** 否则零圈会被报成 −1 圈。±360° 圈数仍只在打开圈数展开的逆解里处理。
4. **偏置和符号从 `resources/robots/fanuc_m10ia.json` 读。** 文件缺失时用编译进程序的常数。限位按 URDF 几何角检查。
5. **尚未对真机，用户决定先不装 ROBOGUIDE。** 耦合系数保持 +1：只动 J2、示教器 J3 仍为 0 时，小臂相对地面的倾角应不变。圈数暂记在 J1、J4、J6，发那科 `$TURN_AXIS` 常是 J4、J5、J6。有真机时用小臂倾角仪区分 +1、0、−1。关节程序在此之前只当草稿。
6. **下一步只补强现有金样。** `DIR-001` 第 4 步要求从 URDF 文件读关节原点，并比较完整姿态。不另写一套正运动学。耦合符号仍由 `RISK-001` 覆盖，URDF 本身没有示教器显示角。
7. **M10 运动学检验与自转角扫描：**
   - 关节软限位检查与 5° 警戒区（`checkJointLimits`）；
   - 奇异点检测（腕 J5=0°、肘伸直、肩部腕中心投影）与可操作度指标（`checkSingularity`）；
   - FANUC 构型锁定与 `ConfigJump` 拦截，确保直线焊接不发生构型跳变；
   - 72 组（5° 步长）绕焊枪 TCP Z 轴自转角可行性扫描（`scanTwistAngles`），自动识别最大连续可行安全区间与最优角。
