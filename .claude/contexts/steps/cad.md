# 几何导入

1. **没有 OCCT 时，平面解析器必须失败而不是假装成功。** 数据行不收在分号上，或出现圆、圆柱、圆锥、球、环面、B 样条、旋转面、偏置面，`importStep` 返回失败。单位先扫全文件：出现不带 milli 的米就乘 1000，否则按毫米。整场景十二个实体、T 型接头四块板仍能导入。没有「安装法兰过渡台」。
2. **机器人 STL 的米到毫米放在加载器，不放在通用 `importStl`。** `importRobotStlMillimeters` 读完再乘 1000。通用导入保持文件单位。
3. **装上 OCCT 之后先编通导入，再决定谁先解析。** `importStepWithOcct` 用 XCAF 读 STEP，边长用弧长积分，面法向用曲面性质。OCCT 8 对旧的索引图和标签序列有弃用警告，还没换新类型。
4. **平面装配仍走内置解析，曲面才落到 OCCT。** XCAF 目前只给出总装配名，认不出 `FANUC_`、`Static_Base`，方案 A 的隐藏和底座对准会坏。所以 `importStep` 先尝试内置解析，失败后再调用 OCCT。管法兰、U 型支架、方管、钢吊架已确认有非直线边和非平面。修出逐个实体的名字之前，不要让 OCCT 抢先解析整场景。
