# 界面拖拽与视口交互

1. **拖拽增量按参考坐标系解释。** 默认仍是工具坐标，所以原来的测试继续成立。世界坐标把增量换到用户坐标系。焊缝坐标在已设置焊缝帧时用该帧变换增量。
2. **零平移且零旋转不提交。** 取消拖拽时，预览回调收到的是按下时的初始位姿；测试若在取消之后读回调，要先清掉回调，否则会把结果盖回初始值。
3. **主窗口与视口当前行为。** 直接运行会加载示例并进入编程工作台；`--verify` 不做窗口。两个工作台都显示场景、属性和点动。编程台额外显示程序和「路径点 | 问题」。程序树不列路径点。路径点表只含当前操作。问题读 `Target::cache`。点动读场景机器人，拖动不入栈。中间视口背景保持深灰。因 Qt 6 在 Windows 下不支持 `WA_PaintOnScreen`，`QWidgetRepaintManager` 会在 `paintEvent` 后对 `QWidget` 自身的 `HWND` 执行 `GDI BitBlt`；现由 `OcctViewport` 内部独立 Win32 透传子窗口承载 `WNT_Window`（父窗口带 `WS_CLIPCHILDREN` 裁剪且开启 `AA_DontCreateNativeWidgetSiblings`），彻底避免点击场景树等非 3D 控件时 `QBackingStore` 把 OpenGL 画面刷黑。左键旋转，中键或右键平移，滚轮向前拉近、向后拉远。工具栏分成文件、编辑、工作台、编程、视图，图标在上、文字在下，组名在按钮下方。全景在视图组。「拾取」按钮已启用并支持工件边拾取。物体采用真实 B-Rep 实体与三角网格渲染（支持 ShadedWithEdges、Shaded、Wireframe），并在视口中用青色亮线绘制三维焊缝。鼠标悬停触发边动态高亮，点击工件边触发拾取并以品红色高亮显示，同时发射 `edgePicked` 信号与回调。选中路径点（Target）时自动在视口中挂载三维手柄（`AIS_Manipulator`），支持 Tool、World、UFrame、Seam 参考系切换与步长吸附，拖拽期间仅发射预览信号驱动状态栏与属性显示，鼠标松开提交单一命令，Esc 键取消回滚，多选批量平移/旋转并打包压入单个 `MacroCommand`。手柄挂载在专用 4mm 黄色球体视觉代理（`targetGizmoProxyAis`）上，绝不直接调用 `Attach()` 绑定文档数据。焊缝模式下根据目标点位置动态匹配最近采样帧并解耦位置与旋转，保证原地微调。

4. **2026-10-26 交叉核定后的分区契约。** 另一窗口的评审见会话记录。始终留下四块：中央 `OcctViewport`、左侧场景树、右侧属性、底栏时间轴，以及右下角节点动。两个工作台都要能看见场景树和点动。编程工作台再加左下「程序」和底栏上方的「路径点 | 问题」页签；布局工作台只隐藏这两块，并换成导入、替换机器人、挂枪、定义坐标系的工具栏。程序树只到控制器、程序、操作和焊缝，点不要再列一层。路径点表只显示当前操作。工艺事件、导出预览、工程保存、碰撞设置都走菜单或对话框，不新开停靠窗。自转角扫描放在选中点的属性里。

5. **类边界。** `MainWindow` 继续做文档、命令、选择集和最近一次仿真缓存，不持有 Qt 视口。`ShellWindow` 只做窗口。`OcctViewport` 由壳创建，接上后删掉占位控件。`ShellWindow.h` 不再包含 `SampleSession.h`。选择集是 `MainWindow` 上的 id 列表，不新建 `SelectionManager`。文档变更继续用 `CommandManager` 的回调，改成可以挂多个监听，不新建事件总线类。点动和属性的写入走现有命令；滑块拖动和 Gizmo 拖动只预览，松手才入栈。
6. **M08 编程工作台与目标点单步联动。** `OcctViewport` 通过 `attachMainWindow` 监听控制器选择变更，选中目标点时自动挂载 `TcpGizmo`；`MainWindow` 提供 `stepTarget` 单步前后导航（绑定键盘 `[` 与 `]`），切换目标点时自动联动程序树当前操作高亮、路径点表当前行高亮并滚动居中、视口手柄挂载，并在目标点具有有效逆解缓存（`cache.valid`）时同步更新机器人连杆位姿与点动面板关节角度。工具栏新增“生成路径”与“SLERP平滑”交互按钮。
7. **局部区间 SLERP 插值（UI-001）、路径点表双击就地编辑与 TCP Z 自转步进面板（M09）。** `ShellWindow` 中姿态平滑检测表格多选，选定 $\ge 2$ 点时自动调用局部区间 SLERP 插值（区间外部点保持不变），单选或未选回退全局；表格扩展至 7 列，支持就地编辑运动、速度、平滑度与工艺事件并使用 `parseSpeedCellText` 解析；引入 `RefreshGuard` 深度计数与 `inItemChanged_` 配合 `QTimer::singleShot(0, ...)` 递延重构，彻底杜绝当前 WidgetItem 在信号派发中被销毁；属性面板集成 TCP Z 自转快捷步进按钮（$\pm 1^\circ, \pm 5^\circ, \pm 15^\circ$）与自定义旋转。
8. **M10 72 组自转角表盘微调控件、构型/奇异度显示与问题列表导航。** 属性面板集成 `TwistScanWidget`（72 组 $5^\circ$ 扇区甜甜圈圆环，按绿/黄/红展示可达、警示与不可达状态，白色指针指示当前角，支持点击、悬停 Tooltip 提示与一键寻优调优 `★ 一键微调至最优自转角`）；属性面板展示 FANUC 构型字串、可操作度指标及逆解关节角；`issueList_` 联动导航（双击或单击问题条目，自动切换选中操作与目标点，高亮路径点表对应行、视口相机手柄挂载至该点、3D 机器人姿态联动更新）。
9. **M13 2D PDF 工位工艺指导报告导出（`WorkcellPdfReportExporter`）。** 基于 `QPdfWriter` + `QPainter`（A4 纵向 300 DPI，可绘区 `2243x3272 px`）输出多页工艺指导书：第 1 页含总览网格、当前视口截图、节拍与占空比指标卡（未仿真时输出 `未仿真` 与 `0.0 %`）、`UTOOL`/`UFRAME`/`ROBOT_BASE` 标定表（双子行）；第 2 页起含焊接工艺条件表（双子行）与操作路径点清单（双子行，含一位小数 `±9999.9 mm` 笛卡尔坐标、满量程 `±180.0 deg` 姿态、带圈数 `FanucConfig`、9 种校验状态与颜色映射及工艺事件），越过页脚自动换页并重绘表头。`MainWindow::exportWorkcellPdfReport` 与文件菜单「导出 2D PDF 工艺报告...」联动。
