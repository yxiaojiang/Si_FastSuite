# 界面拖拽

1. **拖拽增量按参考坐标系解释。** 默认仍是工具坐标，所以原来的测试继续成立。世界坐标把增量换到用户坐标系。焊缝坐标在已设置焊缝帧时用该帧变换增量。
2. **零平移且零旋转不提交。** 取消拖拽时，预览回调收到的是按下时的初始位姿；测试若在取消之后读回调，要先清掉回调，否则会把结果盖回初始值。
3. **主窗口现在能打开，但显隐还不是下面这条契约。** 直接运行 `SiFastSuiteOLP.exe` 会加载示例工位；`--verify` 不做窗口。当前编程工作台会把场景树关掉，点动读的是库里的机器人原型，问题列表来自示例加载结果。中间仍是占位。

4. **2026-10-26 交叉核定后的分区契约。** 另一窗口的评审见会话记录。始终留下四块：中央 `OcctViewport`、左侧场景树、右侧属性、底栏时间轴，以及右下角节点动。两个工作台都要能看见场景树和点动。编程工作台再加左下「程序」和底栏上方的「路径点 | 问题」页签；布局工作台只隐藏这两块，并换成导入、替换机器人、挂枪、定义坐标系的工具栏。程序树只到控制器、程序、操作和焊缝，点不要再列一层。路径点表只显示当前操作。工艺事件、导出预览、工程保存、碰撞设置都走菜单或对话框，不新开停靠窗。自转角扫描放在选中点的属性里。

5. **类边界。** `MainWindow` 继续做文档、命令、选择集和最近一次仿真缓存，不持有 Qt 视口。`ShellWindow` 只做窗口。`OcctViewport` 由壳创建，接上后删掉占位控件。`ShellWindow.h` 不再包含 `SampleSession.h`。选择集是 `MainWindow` 上的 id 列表，不新建 `SelectionManager`。文档变更继续用 `CommandManager` 的回调，改成可以挂多个监听，不新建事件总线类。点动和属性的写入走现有命令；滑块拖动和 Gizmo 拖动只预览，松手才入栈。
